INCIDENT INVESTIGATION REPORT

SOL-501: TELEMETRY RECEIVER STOPPED

Symptom:
TCP connection failed after stopping the receiver.

Evidence:
Successful connection before stopping.
Failed connection after stopping.

Root Cause:
No active listener on port 9101.

Recovery:
Restarted the TCP receiver.


SOL-502: WRONG TELEMETRY PORT

Symptom:
Connection attempted on port 9109.

Evidence:
Port 9109 connection test failed.
Port 9101 connection test succeeded.

Root Cause:
Incorrect TCP port configured by the client.

Recovery:
Use port 9101.
